v0.1.60: SDK maintenance release. Raises the `onekommafive` pin to `>=0.4.0,<0.5` so the integration keeps pace with the upstream v2 endpoint migration.

## Changed

**SDK pin raised to `onekommafive>=0.4.0,<0.5`.** Upstream v0.4.0 migrates the `active-features` endpoint from v1 to v2 (`/api/v2/customers/{id}/sites/{id}/active-features`) and adds a standalone `System.get_device_gateways()` accessor for a richer gateway view than the one nested in `SystemDetails`. The response schema of `get_active_features()` stays identical (`{"features": [...]}`), so no integration-side code change is needed; existing feature-flag sensors keep working unchanged.

The new `get_device_gateways()` accessor is available for future work but not yet wired into the integration.
