## Changed

**SDK pin bumped to `onekommafive>=1.1.8,<2`** (from `>=1.1.7,<2`). v1.1.8 is additive: a new `/api/v1/sites/{id}/system-info` endpoint exposing the site's §14a module (none / Modul 1 / Modul 3) authoritatively, and a per-window `variable_grid_fee_eur_per_kwh` on `HeartbeatPriceWindow` as the counterpart to the already-mapped comparison fee. The integration does not consume these fields yet; the bump keeps the floor in step with PyPI and unblocks a follow-up PR to use them for a verified §14a module readout.

**Shorter config-flow failure WARNING line.** v0.1.68 added a WARNING with the SDK's raw error context, which turned out to include the full Auth0 Universal Login HTML page (~68 KB) when step 2 of the OAuth2/PKCE login rejects credentials. v0.1.69 now reduces that body to its `<title>` plus the byte count — e.g. `Login failed: 1KOMMA5° Sign-in [HTML body suppressed, 68123 bytes]`. Non-HTML bodies above 300 characters are clipped with a `[truncated, N bytes total]` tag. Messages without the `<label>: <body>` shape pass through unchanged. The user-facing form still shows the generic `invalid_auth` / `cannot_connect` label.
