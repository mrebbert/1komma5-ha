v0.1.61: adds the `BATTERY_DISCHARGE_TO_GRID` optimization decision, translated in all seven locales.

## Fixed

**Optimization decision `BATTERY_DISCHARGE_TO_GRID`.** The 1KOMMA5° API emits this decision when the battery discharges into the grid at high spot prices; first surfaced in issue #23. Before this patch the value coerced to `unknown` with a one-line warning. `sensor.<sys>_optimization_last_decision` now lists the value in its ENUM `options` and translates it in every locale (German: "Batterie ins Netz entladen", English: "Discharge battery to grid", analogously for da/es/fi/nl/sv). Regression test pins the mapping.
