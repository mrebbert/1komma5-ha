## What's New

### AI-driven binary sensor: `optimization_heat_pump_recommended`

A second AI-decision binary sensor, symmetric to the existing `optimization_battery_grid_charge`:

- **ON** when the Heartbeat AI's currently active HEATPUMP decision is `HEATPUMP_RECOMMEND_ON`
- **OFF** when the decision is `HEATPUMP_AUTO` or no HEATPUMP event covers the current slot

Lets you automate the heat pump on AI-curated cheap slots without having to subscribe to the bus event.

**Attributes** (when an active HEATPUMP event exists): `decision`, `from`, `to`, `market_price`.

**Example automation** — boost the hot-water target when the AI flags a recommended slot:

```yaml
trigger:
  - platform: state
    entity_id: binary_sensor.SYSTEM_NAME_optimization_heat_pump_recommended
    to: "on"
action:
  - service: number.set_value
    target:
      entity_id: number.water_target_temperature
    data:
      value: 55
```

### Diagnostics download

Home Assistant's standard diagnostics platform is now wired up:

**Settings → Devices & Services → 1KOMMA5° → ⋮ → Download diagnostics**

Produces a redacted JSON dump useful for issue triage:

- Redacted entry data (no username, password, system_id, unique_id)
- Per-coordinator state snapshot: `last_update_success`, `last_exception`, update interval, summary of cached data per coordinator (live / price / optimization / weather)
- Installed `onekommafive` SDK version

Attach this dump to bug reports instead of pasting log fragments — it gives a complete picture in one go.
