The charging-mode select offers the modes the 1KOMMA5° API lists for your site.

## Changed

**Charging modes come from the API.** The select used to offer a fixed list of Smart, Quick and Solar Charge. It now reads the modes your site offers. Sites in an early registration stage, which offer Program Charge instead of Smart Charge, show that mode and keep working. A mode the integration does not know yet stays selectable while it is active. If the list cannot be fetched, the select falls back to the three default modes. Thanks to the author of discussion #83 for the report.

The SDK requirement is now `onekommafive>=1.5.0,<2`, which parses these modes without errors.

## Compatibility

Entity IDs, ``unique_id``s and options-flow fields are untouched. The option order follows the API list. No manual step required.
