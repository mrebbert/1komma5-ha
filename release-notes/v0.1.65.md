v0.1.65: the integration is now fully non-blocking. Backed by the async `onekommafive` SDK 1.0.2.

## Changed

**Every 1KOMMA5° API call runs on Home Assistant's aiohttp loop.** The previous `hass.async_add_executor_job` wraps around SDK calls are gone; the seven data coordinators, both service handlers, the four write-path platforms (switch, select, number, time), the diagnostics dump and the config-flow authentication path all `await` the SDK directly. Detected-blocking-call warnings for `onekommafive` disappear from the log.

**Shared aiohttp session with Home Assistant.** The SDK's `Client` accepts a `session=` parameter as of v1.0.2; setup passes `homeassistant.helpers.aiohttp_client.async_get_clientsession(hass)` so a single connection pool serves both HA and the 1KOMMA5° API. One less socket-set to worry about, and HA's own connection-pool lifecycle carries the SDK too.

**First-class DP price-guarantee endpoint.** Setup uses the SDK's new `system.get_price_guarantee(customer_id)` directly instead of iterating the subscriptions list looking for a `DYNAMIC_PULSE` entry. `sensor.<sys>_dynamic_pulse_price_guarantee` behaves identically; the code path is one endpoint round-trip instead of a list scan.

**Static typing across the SDK boundary.** The `onekommafive` SDK ships `py.typed` since v1.0.2. The integration's runtime data container and per-coordinator dataclasses (`OneKomma5Data`, `LiveData`, `PriceData`, `SystemStatusData`, `OptimizationData`, `NotificationsData`, `EnergyTodayData`, `WeatherData`) now carry concrete SDK types (`System`, `LiveOverview`, `EVCharger`, `Wallbox`, `Asset`, `MarketPrices`, `OptimizationEvent`, `Notification`, `EmsSettings`, `EnergyData`, `SystemDetails`, `DeviceGateway`). Mypy runs clean across the integration.

## Compatibility

**SDK pin bumped to `onekommafive>=1.0.2,<2`** (from `>=0.5.0,<0.6`). Home Assistant installs the new SDK on first reload after the update; no manual step required.

No user-visible entity, service, blueprint or dashboard change. Existing automations that call `onekommafive.assign_ev_to_wallbox`, `onekommafive.refresh_now`, `onekommafive.get_cheapest_window`, `onekommafive.get_most_expensive_window` or `onekommafive.get_heartbeat_metrics` continue to work with the same schema and the same response shape.

## Under the hood

- The base data coordinator's `_fetch` is `async def` and cooperatively cancels on `asyncio.timeout`. The prior wording about "orphaned executor thread" no longer applies; a stalled fetch is actually cancelled at the 30-second mark.
- The 29 duplicated `_setup_entry` test helpers moved into a shared `conftest.py` fixture (`setup_integration`), keeping the integration test surface tighter.
- 267 tests pass. Mypy clean. Ruff clean.
